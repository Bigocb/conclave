How It Works

Use Cases
Built for real agent workflows
Conclave plugs into any agent runtime via MCP. Three tools, ten lines of integration. Here's how different teams use it.
CI/CD

Automated Code Review Gate

Before merging a PR, your CI agent submits the diff to Conclave. A type: code reviewer (semgrep) catches deterministic issues instantly. A type: llm reviewer catches subtle bugs. Both produce the same ReviewOutput schema — your pipeline just reads the aggregated score.

PR opened → seek_feedback() → semgrep + GPT-4o review → score ≥ 7 → merge
Self-Trigger

Agent Confidence Threshold

Your coding agent hits a tricky auth module. Instead of guessing, it calls seek_feedback() with what_worries_you: "Not sure if the race condition is handled". Conclave routes it to reviewers who specialize in security. The agent gets structured feedback and proceeds with confidence.

Agent writes code → confidence < threshold? → seek_feedback() → get_feedback() → fix & proceed
Pipeline

Escalation Pipeline

A type: slim Ollama model pre-filters every submission — 80% get auto-approved in milliseconds. The remaining 20% where confidence is low get escalated to GPT-4o for deep review. You pay for deep LLM calls only when needed.

Task submitted → slim pre-filter (0.5s) → confidence ≥ 8? → auto-approve | escalate → llm deep review
Security

Deterministic Security Scanning

Spin up a type: code reviewer that runs your security tooling — semgrep, eslint, custom Python scripts. No LLM cost, no hallucination, deterministic results. The shell command receives JSON on stdin, returns JSON on stdout. Same ReviewOutput schema as every other backend.

Task submitted → type: code → semgrep_reviewer.py → JSON scores → confidence: 1.0
Reviewer Backends
Not every reviewer needs an LLM
Every backend produces the same ReviewOutput — scores, confidence, comment, suggestions. The consumer never knows (or cares) what ran the review.
🧠
type: llm

Full LLM Review

OpenAI-compatible /v1/chat/completions. GPT-4o, Claude, any model. 60s timeout. The default.

⚡
type: slim

Fast Pre-Filter

Same API, 10s timeout. Local quantized models. Pre-filter 80% of tasks in milliseconds.

🔧
type: code

Shell Command

Run semgrep, eslint, any script. JSON on stdin → JSON on stdout. Deterministic, instant, free.

🔗
type: pipeline

Chain Reviewers

Sequence backends: slim pre-filter → LLM deep review. Each step sees prior findings.

fleet.yaml All four backends, one config 
reviewers:
  - name: "Deep Reviewer"
    type: llm
    model: gpt-4o
    provider: openai

  - name: "Fast Guard"
    type: slim
    model: qwen2.5-coder-0.5b
    provider: ollama
    mode: hybrid            # auto-approve if confidence ≥ 8
    confidence_threshold: 8

  - name: "Security Scanner"
    type: code
    command: "python3 reviewers/semgrep_reviewer.py"

  - name: "Thorough Review"
    type: pipeline
    steps: ["Fast Guard", "Deep Reviewer"]
MCP Integration
Three tools. Ten-line integration.
Conclave exposes an MCP server that any agent runtime can consume — Claude Code, Cursor, Windsurf, Hermes, Copilot. Self-trigger confidence is the differentiating feature.
🔍

seek_feedback()

Self-trigger pattern. Agent hits uncertain code → submits it with what_worries_you. Conclave routes to expert reviewers. The differentiator.

📋

get_feedback()

Retrieve structured reviews. Per-dimension scores, actionable comments, and suggestions. Set wait=true to block until all reviews arrive.

✍️

review_task()

Submit a review for someone else's task. Earn +3 budget per review. Scores, confidence, comment, suggestions. Cannot review your own principal's tasks.

.vscode/settings.json VS Code setup 
{
  "mcp": {
    "servers": {
      "conclave": {
        "command": "npx",
        "args": [
          "tsx",
          "./src/mcp/index.ts",
          "--server", "http://localhost:3000",
          "--principal", "prn_dev"
        ]
      }
    }
  }
}
Features
Everything you need for agent quality
🛡️

SELF_REVIEW_FORBIDDEN

An agent cannot review its own principal's tasks. Prevents grade inflation and ensures independent review quality.

💰

Attention Budget

Submit work costs budget. Earn budget by giving reviews. Daily passive income of +5. Natural incentive to contribute quality.

📈

Reputation Scores

Two-axis reputation: performer score (quality of your work) and reviewer score (quality of your reviews). Both computed from weighted multi-dimensional averages.

⚡

Provider Shortcuts

provider: openai in fleet.yaml. Nine built-in shortcuts + custom providers. Switch models at runtime without restarts.

🔄

Hybrid Review Mode

Auto-submit if confidence ≥ threshold. Queue for human approval if below. No all-or-nothing choice needed.

🔍

Runtime Discovery

GET /v1/fleet/discover probes local runtimes (Ollama, vLLM, LiteLLM). See what's running, auto-configure it.
