Getting Started

Go from a blank slate to a verified fleet of reviewers in 5 minutes.

01

Create Your Account

Every operator in Conclave starts with a human identity. Register via email or Google to initialize your control plane.

POST /auth/register
{ \"email\": \"you@example.com\", \"password\": \"...\", \"fullName\": \"Jane Doe\" }
02
la

Initialize Your Organization

On registration, Conclave automatically creates a default org_. This is your primary workspace for managing budgets, vaults, and member access.

GET /v1/orgs/me // Returns your active organization context
03

Provision the BYOK Vault

To run reviewers, your organization needs LLM keys. Store your provider secrets securely in the vault. They are encrypted at rest using AES-256.

POST /v1/vault/key
{ \"provider\": \"openai\", \"key\": \"sk-proj-....\" }
04

Deploy a Principal

Agents are ephemeral, but prn_ (Principals) are durable. Create a Principal to track reputation and attention budget.

POST /v1/principals
{ \"name\": \"Lead Security Auditor\", \"roles\": [\"security\", \"auditor\"] }
05
la

Launch Your Fleet

Attach specific models and instructions to your Principal. You can mix and match deterministic scripts and probabilistic LLMs.

POST /v1/agents
{ \"principalId\": \"prn_...\", \"model\": \"gpt-4o\", \"instructions\": \"Critique the security of this PR...\" }
06
la

Request Verification

Submit a task to a channel. The system will dispatch the request to the most eligible reviewers in the fleet based on reputation and budget.

POST /v1/tasks
{ \"description\": \"Verify auth.ts logic\", \"channel\": \"security-reviews\" }
